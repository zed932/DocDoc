# DocDoc

## Style Commands

Run these commands from the project root:

```sh
fastlane lint
fastlane format
fastlane style
```

`fastlane lint` checks Swift files with SwiftLint.
`fastlane format` formats Swift files with SwiftFormat.
`fastlane style` formats first, then runs SwiftLint.
